# Natours LP

Landing page for Natours, built with HTML, CSS, and Sass.

## Description

Natours LP is a landing page project developed as part of a Udemy course focused on CSS and Sass.

The project focuses on modern CSS techniques, responsive web design, animations, and Sass architecture to create an attractive and maintainable user interface.

## Technologies

- HTML5
- CSS3
- Sass (^1.105.1)

## Features

- Responsive landing page layout
- Float-based layout
- Custom card designs
- CSS animations and transitions
- CSS positioning and transformations
- CSS shapes and clipping
- Sass variables, mixins, and nesting
- Modular Sass architecture

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/danlakelake/NatoursLP.git
   ```

2. Navigate to the project directory:

   ```bash
   cd NatoursLP
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

## Development

To compile Sass and automatically watch for changes, run:

```bash
npm run compile:sass
```

This command compiles `sass/main.scss` into `css/style.css` and watches for changes in the Sass files.
